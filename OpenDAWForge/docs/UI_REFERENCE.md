# Reference analysis

The attached still is the main workspace: two compact top toolbar rows, a roughly quarter-width browser on the left, playlist track headers and a tightly spaced timeline on the right, and an overlapping channel rack in the lower centre. Tracks and clips use muted green, brick red, ochre, violet and blue. The grid is blue-grey, with lighter bar boundaries and compact labels. Controls are square, bordered and closely spaced; only small buttons and indicators are rounded.

The video at 24 seconds shows a full-workspace piano roll: keyboard left, narrow horizontal pitch rows, darker black-key rows, bar/beat/subdivision lines, mint notes with pitch text, vertical playhead and a separate velocity editor. This informs the second editor view. The displayed third-party synth is not used as an asset or copied implementation.

Decisions where the reference does not establish behaviour:

- LS Factory owns its typography, branding, painted icons, sounds and project format.
- Editors switch through tabs and F5/F7/F9, and the rack can overlap the playlist or sit beneath other editors.
- The supplied images do not expose a detailed mixer, so it uses the same colour/density language with conventional faders, meters, M/S controls and a channel parameter panel.
- Piano roll centers on notes from the selected channel. Ghost notes show other channels. Snap is currently a sixteenth note.
- The timeline uses beat-based coordinates, quarter-beat clip edits and an original automation lane rather than reference assets.
- DPI is handled by JUCE; an explicit 100–300% app zoom setting and fully dockable windows remain unimplemented.
